# 資料導入指南 (Data Import Guide)

## 快速開始

當您有更新或新增的資料需要導入至儀表板時，請按照本指南操作。

---

## 📋 三步驟導入流程

### **步驟 1：準備 SQL 遷移檔案**

將您的資料轉換為 SQL 格式，並放在 `migrations/` 資料夾。

#### 選項 A：新增資料主題（建立新表）

建立檔案：`migrations/YYYYMMDD_import_[topic_name].sql`

範例內容：
```sql
-- 2026-04-24: 深度分析資料導入
-- 建立新表
CREATE TABLE IF NOT EXISTS "public"."deep_analysis_data" (
    id SERIAL PRIMARY KEY,
    location_name VARCHAR(255) NOT NULL,
    analysis_value FLOAT,
    analysis_date DATE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 新增索引（提升查詢效能）
CREATE INDEX idx_deep_analysis_date ON "public"."deep_analysis_data"(analysis_date);

-- 插入資料
INSERT INTO "public"."deep_analysis_data" (location_name, analysis_value, analysis_date)
VALUES 
    ('台北市', 85.5, '2026-04-24'),
    ('新北市', 78.3, '2026-04-24')
ON CONFLICT DO NOTHING;
```

#### 選項 B：更新現有表（僅新增或修改資料）

建立檔案：`migrations/YYYYMMDD_update_[existing_table].sql`

範例內容：
```sql
-- 2026-04-24: 更新空品監測資料
UPDATE "public"."air_station_data"
SET value = 75.5, updated_at = CURRENT_TIMESTAMP
WHERE station_id = 101 AND measure_date = '2026-04-24';
```

### **步驟 2：使用 PowerShell 執行遷移**

#### Windows 環境（推薦）

```powershell
# 進入 migrations 資料夾
cd migrations

# 方法 1：使用現成的 run_all.ps1（適用於空品等既有主題）
Set-ExecutionPolicy -Scope Process Bypass
.\run_all.ps1

# 方法 2：自訂遷移（適用於任何 SQL 檔案）
$SqlFile = "20260424_import_deep_analysis.sql"
$Container = "postgres-manager"
$User = "postgres"
$Database = "dashboardmanager"

# 需要設定密碼
$env:PGPASSWORD = "your_password_here"

# 執行 SQL
Get-Content $SqlFile -Raw | docker exec -i `
  -e PGPASSWORD=$env:PGPASSWORD `
  $Container psql -U $User -d $Database

# 驗證結果
docker exec -i -e PGPASSWORD=$env:PGPASSWORD $Container psql `
  -U $User -d $Database `
  -c "SELECT * FROM deep_analysis_data LIMIT 10;"
```

#### WSL 環境

```bash
# 進入 migrations 資料夾
cd migrations

# 設定變數
SQL_FILE="20260424_import_deep_analysis.sql"
CONTAINER="postgres-manager"
USER="postgres"
DATABASE="dashboardmanager"

# 執行 SQL
cat $SQL_FILE | docker exec -i \
  -e PGPASSWORD=your_password_here \
  $CONTAINER psql -U $USER -d $DATABASE

# 驗證結果
docker exec -i -e PGPASSWORD=your_password_here $CONTAINER psql \
  -U $USER -d $DATABASE \
  -c "SELECT * FROM deep_analysis_data LIMIT 10;"
```

### **步驟 3：驗證與重啟服務**

#### 驗證資料是否成功導入

```sql
-- 在資料庫中執行
SELECT COUNT(*) as record_count FROM deep_analysis_data;
SELECT * FROM deep_analysis_data ORDER BY created_at DESC LIMIT 5;
```

#### 重啟前端服務（讓變更立即生效）

```bash
# 方法 1：重啟前端容器
docker restart dashboard-fe

# 方法 2：完整重啟所有服務
docker compose -f docker/docker-compose.yaml restart
```

#### 在儀表板驗證

- 開啟 http://localhost:8080
- 檢查新資料是否顯示在對應的組件中
- 若無法立即看到，清除瀏覽器快取（Ctrl+Shift+Del）並重新整理

## 🎯 常見場景與範本

### 場景 1：導入來自 CSV 的新資料

若資料是 CSV 格式，先轉換為 SQL：

```powershell
# 使用 PowerShell 將 CSV 轉換為 INSERT 語句
$csv = Import-Csv "data.csv"
$sql = "INSERT INTO deep_analysis_data (location_name, analysis_value) VALUES "
$values = @()
foreach ($row in $csv) {
    $values += "('$($row.location_name)', $($row.value))"
}
$sql += ($values -join ", ")
$sql | Out-File "converted.sql"
```

### 場景 2：排程定期更新（使用 Airflow）

如果需要自動每日或每週更新，應在 `Taipei-City-Dashboard-DE/dags/` 中新增 Airflow DAG。

參考現有的 DAG 結構：`Taipei-City-Dashboard-DE/dags/proj_city_dashboard/[topic_code]/`

### 場景 3：更新有地圖的組件（如空品監測）

如果資料含地理位置，需同時更新 GeoJSON：

```bash
# 執行資料轉換腳本
bash ./migrations/export_[topic]_geojson.sh

# 重啟服務
docker restart dashboard-fe
```

## ⚠️ 重要提醒

### 安全最佳實踐

1. **備份資料** - 執行遷移前，備份當前資料庫
   ```bash
   docker exec postgres-manager pg_dump -U postgres dashboardmanager > backup_$(date +%s).sql
   ```

2. **回滾計畫** - 每次遷移都應準備回滾腳本
   ```sql
   -- rollback_[topic].sql
   DELETE FROM deep_analysis_data WHERE created_at >= '2026-04-24';
   ```

3. **測試環境** - 先在本地測試，再上線生產
   - 使用 `docker-compose-db.yaml` 創建隔離的測試環境

4. **版本控制** - 將遷移檔案提交至 Git
   ```bash
   git add migrations/20260424_import_deep_analysis.sql
   git commit -m "feat: add deep analysis data import (2026-04-24)"
   ```

## 🆘 故障排查

### 問題 1：執行 SQL 時出現「密碼認證失敗」

```powershell
# 確認資料庫密碼是否正確
# 檢查 docker/.env 檔案中的 POSTGRES_PASSWORD

# 手動測試連線
docker exec -it postgres-manager psql -U postgres -d dashboardmanager
```

### 問題 2：資料導入後看不到變更

- 清除瀏覽器快取：Ctrl+Shift+Del（無痕模式）
- 強制重新整理：Ctrl+F5
- 重啟前端：`docker restart dashboard-fe`
- 檢查後端 API 是否正確返回資料：
  ```bash
  curl http://localhost:8088/api/deep-analysis
  ```

### 問題 3：容器無法啟動或連線被拒

```bash
# 檢查容器狀態
docker ps -a | grep postgres

# 查看錯誤日誌
docker logs postgres-manager

# 重啟 Docker Compose
docker compose -f docker/docker-compose.yaml restart
```
