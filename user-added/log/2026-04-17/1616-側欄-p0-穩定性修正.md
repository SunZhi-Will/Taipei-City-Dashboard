# 側欄 P0 穩定性修正 / Sidebar P0 Stability Fix

## 2026-04-17 16:16

- objective:
  - 修正左側導覽列在邊界狀況下的穩定性問題，避免 undefined 導覽與地圖尺寸不同步。

- files:
  - Taipei-City-Dashboard-FE/src/components/utilities/bars/SideBar.vue
  - Taipei-City-Dashboard-FE/src/components/dialogs/MobileNavigation.vue
  - Taipei-City-Dashboard-FE/src/components/utilities/bars/AdminSideBar.vue
  - Taipei-City-Dashboard-FE/src/store/authStore.js
- summary:
  - 為收藏導覽項目新增存在性防護，只有在 favorites.index 存在時才渲染導覽項。
  - 側欄展開與收合皆觸發 map resize，避免只在單向操作時更新地圖 viewport。
  - auth store 補上 viewport 監聽註冊（resize/orientationchange）與裝置狀態重算邏輯，避免 isNarrowDevice 狀態卡住。
- change-type:
  - Fixed
- technical-details:
  - SideBar.vue 與 MobileNavigation.vue：將 favorites tab 的條件由 collapsed 狀態判斷，擴充為 collapsed + favorites.index 存在雙條件。
  - SideBar.vue 與 AdminSideBar.vue：toggleExpand 移除單向 if 判斷，改為每次切換後一律呼叫 mapStore.resizeMap()。
  - authStore.js：新增 hasRegisteredViewportListeners state 與 registerViewportListeners action，於 initialChecks 先註冊監聽並執行 checkIfMobile。
  - authStore.js：checkIfMobile 先重置旗標，再依 maxTouchPoints、pointer coarse/fine 與 innerWidth 重新計算。
- verification:
  - 使用 Problems API 檢查以下檔案無錯誤：
    - Taipei-City-Dashboard-FE/src/components/utilities/bars/SideBar.vue
    - Taipei-City-Dashboard-FE/src/components/dialogs/MobileNavigation.vue
    - Taipei-City-Dashboard-FE/src/components/utilities/bars/AdminSideBar.vue
    - Taipei-City-Dashboard-FE/src/store/authStore.js
  - 檢查方式：執行工具 get_errors，針對上述四檔回傳 No errors found。
- performance-impact:
  - resize/orientation 監聽僅註冊一次，事件處理為常數時間狀態更新，效能影響可忽略。
  - 地圖 resize 在展開與收合都觸發，提升視覺一致性，代價為每次切換多一次 map resize 呼叫（可接受）。
- impact-risk:
  - 影響範圍：dashboard/mapview/admin 左側導覽互動與行動裝置判斷。
  - 已知風險：若未來有 SSR 場景，window 事件需額外保護；目前專案為 client-side SPA，風險低。
- regression-test:
  - 登入與未登入狀態分別檢查左側收藏區塊是否正常顯示且不產生 undefined 路由。
  - 在 mapview 連續展開/收合側欄，確認地圖容器尺寸與控制項位置正常。
  - 模擬視窗寬度跨越 750px 與裝置旋轉，確認 isNarrowDevice 對 UI 顯示切換正確。
  - 驗證 admin 側欄展開/收合後地圖畫面（若存在）不會裁切錯位。
- traceability:
  - Related request: 深度分析左邊導覽列 -> 下一步 修正
- next-actions:
  - P1 建議：抽出共用 SidebarSection 資料模型，讓桌機 SideBar 與 MobileNavigation 不再維護兩套重複邏輯。
