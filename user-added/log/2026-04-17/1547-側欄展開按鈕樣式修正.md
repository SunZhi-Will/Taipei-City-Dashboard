# 側欄展開按鈕樣式修正 / Sidebar Toggle Button Style Fix

## 2026-04-17 15:47

- objective:
  - 修正左側導覽列展開/收起按鈕的互動體驗，移除放大縮小效果並調整配色與側欄主題一致。

- files:
  - Taipei-City-Dashboard-FE/src/components/utilities/bars/SideBar.vue

- summary:
  - 移除按鈕 hover 時的縮放動畫，避免操作時出現跳動感。
  - 將按鈕背景由高亮色改為側欄中性背景色，邊框與圖示顏色改為主題文字/邊框色系。
  - 保留陰影但降低強度，讓按鈕可見且不突兀。

- change-type:
  - Fixed

- technical-details:
  - 修改 .sidebar-collapse-btnContainer-button 樣式：
  - transition 從 transform + box-shadow 改為 background-color + border-color + box-shadow。
  - 移除 &:hover 的 transform: scale(1.08)。
  - background-color: var(--color-component-background)。
  - border: 1px solid var(--color-border)。
  - icon 顏色改為 var(--color-normal-text)。

  - 執行錯誤檢查：get_errors Taipei-City-Dashboard-FE/src/components/utilities/bars/SideBar.vue
  - 結果：No errors found。
  - 樣式核對：確認已無 transform: scale(...) 作用於展開/收起按鈕 hover。

- performance-impact:
  - 減少 hover 觸發的 transform 動畫，降低不必要的重繪/合成變化。
  - 預期互動穩定度提升，無可見效能退化。

- impact-risk:
  - 影響範圍僅限左側導覽列展開/收起按鈕視覺樣式。
  - 低風險，未更動任何業務邏輯與資料流。

  - 測試深淺背景主題下按鈕與圖示可讀性。
