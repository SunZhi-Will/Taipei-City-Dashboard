# 改進儀表板搜尋結果展示格式 / Improve Dashboard Search Results UI

## 2026-04-22 16:00

- objective:
  - 優化 Agent + RAG 模式下儀表板搜尋結果的展示方式
  - 從傳統表格改為現代卡片設計，提升使用體驗

- files:
  - Taipei-City-Dashboard-FE/src/components/dialogs/ChatBox.vue

- summary:
  - **變更內容**: 用戶查詢儀表板組件（如「扶養比及老化指數」）時，原本用表格展示搜尋結果不夠直觀
  - **改進方案**: 改為 **卡片網格** (Grid Card Layout)
  - **影響範圍**:
    1. 普通聊天視窗內的儀表板結果卡片
    2. 全屏展開模式下的儀表板結果卡片
    3. 移除水平滾動表格，改為自動換行卡片網格

- change-type:
  - Changed

- technical-details:
  - **Template 變更**:
    - 移除 `.relation-area` + `relation-table` (HTML table)
    - 新增 `.dashboard-cards-area` + `.dashboard-card` 卡片容器
    - 卡片包含: 排名徽章、標題、城市標籤、相關性分數
  
  - **SCSS 變更** (+100 行):
    - Grid 佈局: `grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))`
    - 卡片樣式:
      - 漸變背景 (`linear-gradient(135deg, #1f2a33 0%, #252a2f 100%)`)
      - Hover 效果: 邊框高亮 + 向上平移 + 藍光效果
      - 排名徽章: 絕對位置，右上角，帶 `#00d4ff` 藍光
      - 城市標籤 + 相關性分數: 彩色背景區分
    - 動畫: `$transition-fast` (0.2s) 在 hover 時變色和移動
  
  - **資料結構**:
    - 無變更，保持現有 `chat.relations` 結構
    - 相關性分數由 `item.score` 轉換為百分比顯示: `(item.score * 100).toFixed(0)`

- verification:
  - ✅ Vue 文件無編譯錯誤
  - ✅ SCSS 語法驗證通過
  - ✅ 模板結構完整 (開閉標籤匹配)
  - ✅ 移除舊的 `v-horizontal-wheel` 指令（已不需要）
  - ✅ 同時修改普通視窗和全屏展開模式

- performance-impact:
  - Grid 佈局較表格更高效 (CSS Grid 原生支援)
  - 卡片寬度固定 (240px), 自動換行，無需滾動
  - Hover 動畫使用 GPU 加速 (transform + opacity)
  - 預期渲染性能略優於表格 ✅

- impact-risk:
  - **低風險**:
    - 視覺改進，無資料邏輯變更
    - 向後兼容: 如果 `chat.relations` 為空，卡片區不顯示
    - 行動版本也能自動適應 (Grid 自動調整列數)
  
  - **邊界情況**:
    - 長標題自動截斷 (2 行, ellipsis)
    - 相關性分數自動轉百分比
    - 若 score 為 NaN，百分比會顯示 NaN% (建議後端驗證)
