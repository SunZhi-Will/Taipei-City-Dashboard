# 2026 Roadmap 與 KPI

日期: 2026-04-14

## 1. 目標

在不破壞官方既有主線的前提下，將你去年黑客松成果轉為可上線、可維運、可驗收的正式能力。

## 2. 範圍

- in scope:
  - 原住民
  - 新住民/移工
  - 垃圾清運
  - 文件治理與分類
- out of scope (先治理後決策):
  - AED
  - 長照
  - 老人
  - 學區

## 3. 時程與里程碑

### M1 (第 1 週)
1. 完成文件整併與分類
2. 完成差異化主題資料契約草案
3. 建立主題優先級與責任分工

### M2 (第 2-3 週)
1. 差異化主題 DAG 化
2. 補資料品質驗證
3. FE 圖層整合與命名標準

### M3 (第 4 週)
1. 完成 UAT 驗收
2. 產出月度品質報告
3. 凍結版本準備上線

## 4. KPI

1. 主題上線數: >= 3
2. DAG 成功率: >= 98%
3. 品質告警處理時效: <= 24h
4. 文件完整率: 100%
5. 需求到上線週期: <= 4 週

## 5. 風險與緩解

1. 主題重疊造成重工
- 緩解: 先做主題對照表與白名單

2. 欄位口徑不一致
- 緩解: 先定 schema 再開發

3. FE 多圖層混用
- 緩解: 建立唯一資料來源標記

## 6. 下一步 (Action Items)

1. 建立原住民資料契約 v1
2. 建立移工資料契約 v1
3. 垃圾清運資料納入 DE 排程
4. 與官方維護者確認重疊主題治理原則
