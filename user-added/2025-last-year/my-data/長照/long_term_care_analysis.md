# 長照ABC政策分析與數據應用

## 一、長照ABC政策概述

### 1. 政策背景
- 長照2.0的核心精神：社區整體照顧、在地老化
- 目標：建立綿密的社區照顧網絡，讓長者在熟悉的環境中獲得適切照顧

### 2. ABC三級據點功能

| 級別 | 名稱 | 主要功能 | 服務內容 |
|-----|------|---------|---------|
| A級 | 社區整合型服務中心 | 擬定照顧服務計劃，整合B、C級資源 | 評估需求、擬定照顧計劃、資源連結 |
| B級 | 複合型服務中心 | 提供多元複合服務 | 日間照顧、社區復健、小規模多機能、團體家屋 |
| C級 | 巷弄長照站 | 初級預防功能 | 共餐、送餐、健康促進、預防延緩失能課程 |

### 3. 政策發展現況
- 截至2023年，全國已佈建數千個ABC據點
- 涵蓋全台22個縣市
- 目標：469個A級、829個B級、2,529個C級據點

## 二、數據分析方向

### 1. 據點覆蓋率分析

```sql
-- 計算各行政區ABC據點密度
SELECT 
    "縣市",
    "區",
    COUNT(*) AS "據點總數",
    ROUND(COUNT(*) * 100000.0 / "人口數", 2) AS "每十萬人據點數",
    SUM(CASE WHEN "O_ABC" = 'A' THEN 1 ELSE 0 END) AS "A級據點",
    SUM(CASE WHEN "O_ABC" = 'B' THEN 1 ELSE 0 END) AS "B級據點",
    SUM(CASE WHEN "O_ABC" = 'C' THEN 1 ELSE 0 END) AS "C級據點"
FROM 
    long_term_care_abc_metro
GROUP BY 
    "縣市", "區", "人口數"
ORDER BY 
    "每十萬人據點數" DESC;
```

### 2. 服務類型分析

```sql
-- 分析各類服務項目分佈
SELECT 
    "特約服務項目",
    COUNT(*) AS "據點數量",
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM long_term_care_abc_metro), 2) AS "佔比(%)"
FROM 
    long_term_care_abc_metro
GROUP BY 
    "特約服務項目"
ORDER BY 
    "據點數量" DESC;
```

### 3. 與村里、學區交叉分析

```sql
-- 與村里資料交叉分析
SELECT 
    v."村里名稱",
    v."村里代碼",
    COUNT(l."機構代碼") AS "長照據點數",
    v."65歲以上人口" AS "高齡人口數",
    ROUND(COUNT(l."機構代碼") * 1000.0 / v."65歲以上人口", 2) AS "每千位長者據點數"
FROM 
    village_data v
LEFT JOIN 
    long_term_care_abc_metro l 
    ON ST_Within(
        ST_SetSRID(ST_MakePoint(l."經度", l."緯度"), 4326),
        v.geom
    )
GROUP BY 
    v."村里名稱", v."村里代碼", v."65歲以上人口", v.geom
ORDER BY 
    "每千位長者據點數" DESC;
```

## 六、數據分析建議

### 1. 與村里資料交叉比對
- 使用空間分析技術，將長照據點與村里邊界圖層疊合
- 計算每個村里的據點可及性
- 識別服務缺口區域

### 2. 與學區資料整合
- 分析學區與長照據點的空間關係
- 探討代間共融的可能性
- 評估學區轉型為多世代服務據點的可行性

### 3. 人口老化趨勢分析
- 預測未來高齡人口分佈
- 預先規劃據點擴增策略
- 動態調整資源配置

### 4. 服務使用行為分析
- 分析不同區域的服務使用偏好
- 識別服務使用障礙
- 優化服務提供方式

## 七、政策建議

1. **資源優化配置**
   - 針對高齡人口密集但據點不足區域增設據點
   - 強化偏遠地區服務輸送

2. **服務整合**
   - 促進ABC三級據點橫向連結
   - 強化醫療與長照服務整合

3. **數位轉型**
   - 建立服務預約平台
   - 發展遠距照護服務
   - 導入智慧照護科技
